# 🔐 Flutter Firebase Auth + Realtime Database CRUD App

A simple Flutter application that allows users to **sign up**, **log in**, and perform **CRUD operations** on data using **Firebase Realtime Database**.

- 🔐 **Email/Password Authentication** using Firebase Auth
- 📥 **Create**, **Read**, **Update**, and **Delete** user data
- 🔄 Real-time data syncing via Firebase Realtime Database
- 📱 Built with **Flutter** for cross-platform support (Android/iOS)
- 🧠 Uses **Riverpod** for clean and reactive state management
- 💡 Clean UI and simple UX for learning and demonstration purposes

---

## 🛠️ Technologies Used

- **Flutter** (Dart)
- **Firebase Authentication**
- **Firebase Realtime Database**
- **Riverpod** (State Management)
- **Firebase Core**, **Firebase Auth**, **Firebase Database** packages
